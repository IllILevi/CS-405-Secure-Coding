# CS-405-Secure-Coding

This is a collection of the schoolwork I've done for CS-405: Secure Coding at Southern New Hampshire University. 



## Security Policy Presentation.
This was the final project, where I had to create and present a security policy using SEI CERT's C++ Coding Standard as the framework. In addition I created a threat matrix based on selected vulnerabilites as well as demonstrated unit testing utilizing the unit testing framework GUnit.
